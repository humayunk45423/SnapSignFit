# SnapSignFit

SnapSignFit is a 100% free, privacy-first, client-side web application for auto-formatting and resizing photos and signatures to exact pixel dimensions and byte constraints (under 99 KB for BCS/gov standards, passport/visa requirements, and custom dimensions).
